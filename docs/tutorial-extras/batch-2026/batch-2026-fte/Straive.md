# Straive Interview Experience

**Article By:** —  Hitanshu Satpathy 
**Company Name:** Straive  
**Job Description:** Associate Data Science Engineer  
**CTC Offered:** 14 LPA  
**Location:** Bangalore

---

## Round 1 — Online Assessment

**Mode:** Online

**Content:**

- **MCQs:** 20–30 questions from Core CS and Quantitative Aptitude topics.
- **SQL Coding:** 2 questions.
- **DSA Coding:** 2 questions focused on data analysis.

---

## Round 2 — Technical Interview 1

This round was primarily focused on the **Data Science role**.

### Topics Discussed

- **Projects & Data Analytics**

  Discussion regarding projects and previous exposure to data analytics.

- **Project Deep Dive**

  Extensive discussion about the **Interview Bot project**, including its implementation and technical aspects.

- **Exploratory Data Analysis & Classification**

  Performed **Exploratory Data Analysis (EDA)** on a given binary classification dataset.

  The problem was later extended to a **multi-class classification** problem.

- **Data Cleaning & Pipelines**

  Discussed:

  - Data cleaning approaches
  - Complete EDA pipeline
  - ETL pipeline
  - Data preprocessing techniques
  - Data visualization methods

- **SQL Questions — Easy to Medium**

  Questions included:

  - Find the second-highest salary of an employee.
  - Write a query to find and remove duplicate rows from a table.

- **Python Questions**

  Discussed:

  - `try-except` block and error-handling mechanisms
  - Python dictionary operations
  - Combining values of common dictionary keys
  - Difference between **deep copy and shallow copy**

- **Machine Learning**

  Discussed:

  - Different types of Machine Learning models
  - Regression vs. Classification
  - Use cases of Regression and Classification models

> **Quick Tip:** Following the Data Science and AI subject notes thoroughly can be very helpful for this round.

---

## Round 3 — Technical Interview 2: System Architecture

This round focused on **System Design and high-level architecture**, particularly for AI-based systems.

### Topics Discussed

- **LLM System Design**

  Asked to design an **LLM from scratch**, similar to ChatGPT.

  Discussion included:

  - System requirements
  - High-level architecture
  - APIs
  - Major system components

- **RAG Pipeline**

  Discussed:

  - Document ingestion
  - Document parsing
  - RAG pipeline architecture
  - Retrieval process
  - Selecting the Top-K relevant passages/chunks

- **SQL Questions — Medium to Hard**

  Questions included:

  - Write a query to calculate a **rolling 7-day average** for sales.
  - Find the **top 3 highest-earning employees in each department** using window functions.

- **Previous Experience**

  Discussed all projects completed prior to this interview experience.

- **Oracle Internship**

  Discussed:

  - Team management at Oracle
  - Collaboration and teamwork
  - Internship experience

- **Product Management Questions — Easy**

  Questions included:

  - How would you prioritize features for a new data product?
  - How would you measure the success and impact of a newly deployed model?

- **APIs & OpenAI**

  Discussed:

  - API-based projects
  - RESTful APIs
  - OpenAI integrations

## Round 4 — HR Round

### Topics Discussed

- Career aspirations and educational journey.
- Managing heavy workloads.
- Prioritizing and deprioritizing tasks.
- Motivation for joining Straive.
- Current and preferred location.

### Question Asked by Me

> Since Straive is doing great on the data side, what are their contributions in the Generative AI space?

---

## Notes for Juniors

- **Master SQL Window Functions:** They are important for the Medium-to-Hard SQL questions in the later rounds.

- **Know Your Projects:** Be prepared to explain and defend your projects in detail, especially **ETL and EDA pipelines**, and discuss how they could be scaled.

- **Understand RAG and LLM Architecture:** High-level AI system design is an important part of the interview process.

- **Be Thorough with Data Science & AI Topics:** Significant emphasis was placed on **data analysis pipelines, preprocessing, EDA and Machine Learning concepts**.
