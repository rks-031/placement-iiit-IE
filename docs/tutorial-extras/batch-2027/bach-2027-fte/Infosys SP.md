## Round 2 — Coding Assessment

**Duration:** 45 minutes

**Mode:** Online — Infosys Wingspan

**No. of Questions:** 2

### Content

A second coding assessment was conducted after the initial Online Assessment. There were 2 coding questions, one of **Medium** difficulty and one of **Hard** difficulty.

### Questions

#### 1. Height Array / Backtracking Problem

Given an array of heights, selecting an element adds its current height to the score.

After selecting an element at index `i`, the next `d` elements are updated based on the difference between the selected height and their current heights.

The updated values affect which elements can be selected subsequently.

The objective is to determine the **maximum score** that can be obtained.

The array length was small, around 15, making a **backtracking approach** feasible.

#### 2. Perfect Cube Subsequence

Given an array of integers, find a subsequence such that the **product of the selected elements is a perfect cube**, i.e., its cube root is an integer.

The problem involved reasoning about the **prime factorization** of the product. Each number was constrained to have at most 6 prime factors.

## Round 3 — Technical & HR Interview

The interview consisted of a technical discussion followed by a few HR/behavioural questions.

### 1. DSA Questions

#### Sum of Maximum and Second Maximum

Given an array, find the sum of the maximum and second maximum elements.

The interviewer asked to explain multiple approaches, starting from the **brute-force approach** and moving towards the **optimal approach**.

#### Linked List Cycle

Detect whether a cycle exists in a linked list and find the node where the cycle begins.

The interviewer asked to explain the intuition behind the optimal approach using **slow and fast pointers**.

This is similar to **LeetCode 142 — Linked List Cycle II**.

#### Trapping Rain Water

Given an array representing the heights of bars, calculate the amount of rainwater that can be trapped.

The interviewer specifically asked about the **two-pointer approach**.

This corresponds to **LeetCode 42 — Trapping Rain Water**.

#### Kadane's Algorithm

Find the maximum subarray sum using **Kadane's Algorithm**.

This corresponds to **LeetCode 53 — Maximum Subarray**.
