# Infosys DSE Interview Experience

**Article By:** Nabin Agrawal

**Company Name:** Infosys

**Job Description:** Specialist Programmer (SP) / Digital Specialist Engineer (DSE)

---

## Round 1 — Online Assessment

**Mode:** Online — Wingspan App

**Location:** Silicon University

**Duration:** 3 hours

**Content:**

The assessment consisted of 4 coding questions with different difficulty levels:

- **Easy**
- **Medium**
- **Hard**
- **Complex**

**No. of MCQ Questions:** 0

**No. of DSA Questions:** 4

**No. of Aptitude Questions:** 0

**Selection Criteria:** Candidates had to solve any 3 out of 4 questions.

**My Experience:** I was able to solve 2 questions completely and the 3rd question partially.

### Questions Asked

1. **Easy — Digit Sum with Local Maxima**

   Given a digit array `nums`, the task was to find peak elements based on specific conditions and increase the counter whenever the conditions were satisfied.

   The digit sum of `nums[i]` had to be greater than the digit sums of its neighboring elements. If the digit sums were equal, the original values were compared and counted accordingly for both neighbors.

2. **Medium — Greedy**

   The exact question was not remembered, but it was based on the **Greedy approach**.

3. **Hard — Video Clips**

   Given a set of video clips that needed to be merged, the task was to return the **maximum possible difference between your pick and your friend's pick**.

4. **Complex — Pizza With 3n Slices**

   The problem was based on **LeetCode 1388 — Pizza With 3n Slices**.

## Round 3 — Technical Interview

**Mode:** Offline — In-person

**Location:** Infosys Campus, Bhubaneswar

**Duration:** Approximately 20 minutes

### DSA & Algorithms

- **Maximum Subarray Sum**

  The problem was coded during the interview.

- **Linked List Cycle II**

  **LeetCode 142 — Linked List Cycle II**

  The interviewer asked only for the **approach and underlying logic**.

- **Find the Unique Element in an Array**

  The interviewer asked only for the **optimal approach**.

- **GCD and LCM**

  GCD and LCM were coded on paper, including their relationship.

- **Linked List Complexity**

  Asked about the time complexity of extracting the **last node from a Linked List**.

- **Algorithmic Complexity**

  Discussed the time complexity of:

  - Quick Sort
  - Binary Search
  - Merge Sort

### CS Fundamentals

- **OOPS**

  No questions were asked from OOPS.

- **DBMS**

  Discussed:

  - `DELETE` vs. `TRUNCATE`
  - ACID Properties

- **Operating Systems**

  Discussed:

  - Process vs. Thread
  - Semaphore
  - Deadlock

- **Computer Networks**

  No questions were asked from Computer Networks.

### Project Discussion

No project-specific questions were asked during the technical interview.

## Preparation Advice

Candidates preparing for the Infosys **SP/DSE** roles should focus on:

- **DSA**
- Arrays
- Linked Lists
- Greedy Algorithms
- Dynamic Programming
- Bit Manipulation
- Sorting and Searching
- Time and Space Complexity
- GCD and LCM
- DBMS fundamentals
- Operating Systems fundamentals

Also practice explaining the **approach and intuition** behind a solution, as the interviewer may ask for the logic without requiring complete code.
