## Round 1 — Online Assessment

**Mode:** Online

**Duration:** 2 hours

**Content:**

The assessment consisted of:

- **No. of DSA Questions:** 7
- **No. of MCQ Questions:** 30+

**Difficulty & Topics:**

The coding questions were mostly LeetCode Medium-level problems, primarily based on:

- Arrays
- Strings
- Dynamic Programming (DP)
- Grid BFS/DFS

**Duration:** 1 hour

**Interview Experience:**

The interview was conducted through an interactive coding interface, where the problem statement was displayed on one side and the coding editor was available on the other side.

For each problem, the AI interviewer asked me to:

- Write the code in the provided editor.
- Explain the code and underlying logic.
- Explain the time and space complexity.
- Discuss how the solution could be optimized, if possible.

## Round 4 — HR + Technical Interview

**Mode:** Offline — On-campus

**Duration:** 30 minutes

### 1. Questions Related to Introduction

- Tell me about yourself.
- Questions about my academic background and technical skills.

### 2. Questions About Internship / Experience

- Asked about my internship experience.
- Since I had **no internship experience**, the interviewer asked whether I had worked on any **group project**.
- I explained my group project and my contribution to it.

### 3. Questions on Projects

- Explain your group project.

Since the project was based on **data and solving a real-world problem**, the interviewer asked:

- What can you do with the available data?
- How can you perform **data analytics** on it?
- How can you create a **dashboard** to visualize the data?

### 4. Technical Questions

**DBMS Concepts:**

- What is **Normalization**?
- Why is normalization required?
- Explain **ACID Properties**.

**SQL Question:**

Given the following three tables:

**Orders:** `order_id, user_id, product_id, quantity, amount, ...`

**User:** `user_id, name, ...`

**Product:** `product_id, product_name, price, ...`

**Problem Statement:**

Find the **single user who has placed orders and whose total spending across all orders is the highest**.

The solution required:

- Calculating the total order amount for each user.
- Grouping the orders based on `user_id`.
- Finding the user with the highest total spending.

### 5. HR Questions

- What do you know about **Sigmoid**?
- What is a **Data Engineer**?
- Questions about family background.
- If given a preference between working as a **Data Engineer or Software Engineer**, which one would you choose?

**Interview Experience:**

The round consisted of a combination of **project discussion, SQL/DBMS concepts, data analytics, and HR/behavioral questions**.

## Overall Experience

The interview process mainly focused on:

- DSA and Problem Solving
- C++ Fundamentals
- SQL and DBMS
- Project Understanding
- Data Analytics
- Time and Space Complexity
- Optimization of Solutions

Candidates preparing for the **Sigmoid Analytics Data Engineering Intern + SDE Trainee** roles should focus on solving DSA problems, strengthening C++ fundamentals, and understanding SQL and DBMS concepts.

Be prepared to explain your **approach and intuition before coding**, discuss time and space complexity, and optimize your solutions whenever required.

Projects may also be discussed in depth, particularly with a focus on **how available data can be analyzed, visualized through dashboards, and used to solve real-world problems**.
